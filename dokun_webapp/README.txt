道訓 暗記トレーナー Webアプリ版

【公開方法：GitHub Pages】
1. GitHubで新しい公開リポジトリを作ります。
2. このフォルダ内の index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png をルートにアップロードします。
3. リポジトリの Settings → Pages → Build and deployment → Deploy from a branch を選択します。
4. Branchを main、フォルダを /(root) にして Save。
5. 公開された https://ユーザー名.github.io/リポジトリ名/ をSafariで開きます。
6. iPhone Safariの共有 → ホーム画面に追加を選びます。

【注意】
・ZIPを直接内蔵ブラウザで開いても、Webアプリとしての機能は保証されません。HTTPSで公開してください。
・本文/読み仮名は元のトレーナーと同じ参考データを使用しています。
・マイクによる音声認識はブラウザによって対応が異なり、オフライン時は利用できない場合があります。
・学習履歴は閲覧環境ごとの保存です。学習記録 → 履歴を書き出す/読み込むで移動してください。
・すでに別のURLまたはファイルで保存した進捗は自動同期されません。
